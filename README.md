# 🌍 Pembelajaran Pembentukan Bumi & Teorinya

Platform pembelajaran interaktif tentang asal mula dan teori-teori pembentukan planet Bumi.

## 🌐 Akses Website

**👉 [BUKA WEBSITE DI SINI](https://khailakurniade-arch.github.io/Pembentukan-bumi-dan-Teorinya/)**

Website sudah live dan siap digunakan!

## 📚 Konten Pembelajaran

### 10 Modul Pembelajaran:
1. **Selamat Datang** - Pembukaan dan ringkasan materi
2. **Tujuan Pembelajaran** - Objektif pembelajaran
3. **Apa Itu Bumi?** - Pengenalan planet Bumi
4. **Proses Pembentukan** - Tahapan pembentukan Bumi
5. **Teori Nebula** - Teori paling diterima oleh ilmuwan
6. **Teori Planetesimal** - Teori penggabungan benda kecil
7. **Teori Pasang Surut** - Teori alternatif pembentukan
8. **Teori Bintang Kembar** - Teori lanjutan
9. **Quiz Interaktif** - 5 pertanyaan dengan feedback otomatis
10. **Penutup** - Ringkasan dan kesimpulan

## 🎯 Target Audiens

- Siswa SD Kelas 5-6
- Pelajar yang tertarik dengan geografi dan astronomi
- Siapa saja yang ingin belajar tentang pembentukan Bumi

## 📝 Cara Menggunakan

1. Buka link website di atas
2. Klik menu di sidebar kiri untuk navigasi
3. Baca materi dengan seksama
4. Lanjut ke modul berikutnya
5. Kerjakan quiz untuk test pemahaman
6. Lihat ringkasan di penutup

## 💾 Cara Mengakses Lokal

1. Clone repository ini:
```bash
git clone https://github.com/khailakurniade-arch/Pembentukan-bumi-dan-Teorinya.git
```

2. Buka file `index.html` di browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
firefox index.html
```
